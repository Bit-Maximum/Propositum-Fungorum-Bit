## 2. Общие положения

Настоящее программное обеспечение **Propositum-Fungorum**, включая, но не ограничиваясь:
- исходным кодом,
- архитектурой системы,
- промптами для моделей искусственного интеллекта,
- логикой взаимодействия компонентов,
- файловой структурой,
- документацией и описаниями,

является объектом авторского права и принадлежит указанным выше авторам
на правах совместного авторства.

Все права, прямо не предоставленные настоящей лицензией,
**сохраняются за авторами**.
