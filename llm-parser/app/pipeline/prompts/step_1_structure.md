в заданный JSON без изменения формулировок.

СТРОГИЕ ПРАВИЛА:
1. Все значения "name" должны быть ДОСЛОВНЫМИ фрагментами текста.
2. Запрещено:
   - переименовывать
   - сокращать
   - обобщать
   - классифицировать
3. Один абзац текста → не более одного элемента JSON.
4. Если ты сомневаешься, к какому уровню отнести фрагмент —
   помещай его на САМЫЙ НИЖНИЙ возможный уровень.
5. НЕ создавай сущности, которых нет в тексте.
6. НЕ создавай категории по умолчанию.

Извлеки ТОЛЬКО структуру хирургического лечения.
ИСКЛЮЧИ: условия, причины, показания, возраст, противопоказания, цели, прогнозы, сравнения.

ПРАВИЛА ДЛЯ operation_parameters:
1. operation_parameters — это любые дословные технические, инструментальные или конструктивные характеристики операции, указанные в том же абзаце.
в том числе:
- количественные значения
(например: 25 мм, 8–10 недель, 240 мм, 15±10°)
- требования к положению, ориентации, доступу, фиксации
(например: антеверсия 10–15°, Tip-Apex Distance менее 25 мм)
- характеристики импланта или конструкции
(например: бесцементная фиксация, длина не менее 240 мм)
- варианты выполнения операции
(например: в динамическом варианте, в статическом варианте)
К ним ОБЯЗАТЕЛЬНО относятся фразы, начинающиеся с:
- "при помощи"
- "с помощью"
- "с использованием"
- "с применением"
- "с возможностью"
- "перечисления имплантов, винтов, фиксаторов"
- "характеристики фиксации, конструкции или погружения"
Если такие фразы присутствуют в тексте абзаца —
operation_parameters НЕ МОЖЕТ быть пустым

2. Каждый параметр заносится отдельной строкой массива.
3. Формулировки параметров НЕ ИЗМЕНЯТЬ, брать дословно из текста.
4. Если параметры указаны списком — разбивать на отдельные элементы массива.
5. Если параметров нет — возвращать пустой массив [].

ПРАВИЛА ДЛЯ diagnosis_parameters
1. Заполняются только если параметры диагноза явно присутствуют в том же абзаце
(например: классификационные индексы, типы, номера).
2. Формулировки — строго дословные.
3. Если отсутствуют — [].


Важные ограничения
1. Уровни не могут дублироваться.  
2. surgical_models.name и operations.name не могут содержать одинаковые строки.

              "name": "string",

            }

        }
      ]
    }
  ]
}

Если категория диагнозов не указана явно — используй одну категорию
с названием "Без категории".

Если элемент отсутствует в тексте — верни пустой массив.
