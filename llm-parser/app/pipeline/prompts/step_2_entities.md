Твоя задача —
извлечь ТОЛЬКО ДОСЛОВНЫЕ непрерывные фрагменты текста,

Если соответствие не является очевидным — НЕ извлекай.

────────────────────────────
СТРОГИЕ ПРАВИЛА ИЗВЛЕЧЕНИЯ
────────────────────────────

1. Каждая сущность = ОДИН непрерывный фрагмент текста.
   • нельзя объединять части из разных мест текста
   • нельзя расширять или сокращать фрагмент

2. Фрагмент копируется ДОСЛОВНО:
   • сохраняй регистр, пробелы, дефисы, тире, скобки
   • НЕ изменяй формулировку
   • НЕ нормализуй
   • НЕ расшифровывай сокращения

3. ЗАПРЕЩЕНО:
   • домысливать отсутствующие слова
   • заменять сокращения
   • исправлять опечатки
   • объединять похожие формулировки
   • извлекать «по смыслу»

4. Перечисления и диапазоны:
   • если в одном фрагменте указано несколько значений
     И в них присутствуют римские цифры (I, II, III, IV, V),
     ТЫ ОБЯЗАН разбить их на ОТДЕЛЬНЫЕ сущности
   • если римских цифр нет — НЕ разбивай

5. ОБЯЗАТЕЛЬНЫЕ ПРИМЕРЫ:
   • "Garden I-II" → "Garden I", "Garden II"
   • "Garden III–IV" → "Garden III", "Garden IV"
   • "Pipkin I-IV" → "Pipkin I", "Pipkin II", "Pipkin III", "Pipkin IV"

6. Запрещено:
   • создавать диапазоны
   • добавлять пропущенные номера
   • связывать сущности между собой

7. Принцип осторожности:
   • если есть сомнение — ИЗВЛЕКАЙ МЕНЬШЕ, А НЕ БОЛЬШЕ
   • лучше пропустить сущность, чем извлечь лишнюю
