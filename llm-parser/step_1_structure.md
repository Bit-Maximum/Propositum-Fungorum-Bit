ДЕТЕРМИНИРОВАННОСТЬ (ОБЯЗАТЕЛЬНО):
1) Порядок:
   - Обрабатывай абзацы строго по возрастанию "index".
   - Внутри одного абзаца порядок сущностей — как в тексте (слева направо, сверху вниз).
   - В итоговых массивах сохраняй порядок появления в документе (НЕ сортируй по алфавиту).
2) source_text — якорь:
   - Для КАЖДОГО объекта на любом уровне (категория/диагноз/модель/операция)
     поле "source_text" ДОЛЖНО быть ТОЧНО РАВНО значению "text" одного (и только одного) абзаца из входного массива.
   - Никаких изменений: не правь регистр, пробелы, тире, знаки, не добавляй/убирай символы.
   - Один объект = один абзац-источник. Не смешивай куски из разных абзацев.
3) name:
   - Все значения "name" должны быть ДОСЛОВНЫМИ фрагментами текста того же абзаца, который указан в "source_text".
   - Запрещено переименовывать, сокращать, обобщать, исправлять опечатки.
4) Повторы:
   - Если на одном уровне уже был создан элемент с тем же "name" ранее (в более раннем абзаце),
     НЕ создавай новый дубль позже. Используй ранее созданный элемент.
5) Ограничение абзаца:
   - Один абзац → не более одного нового элемента на самом нижнем возможном уровне.
     (Обычно это операция. Если в абзаце непонятно — клади ниже.)

СТРОГИЕ ПРАВИЛА:
1. Не создавай сущности, которых нет в тексте.
2. Не создавай категории “по умолчанию”, кроме правила ниже.
3. Извлеки ТОЛЬКО структуру хирургического лечения.

Верни СТРОГО валидный JSON следующей структуры
(ключи в объектах выводи в точном порядке, как показано ниже):

Если категория диагнозов не указана явно — используй одну категорию

Если элемент отсутствует в тексте — верни пустой массив.

ПРАВИЛА ДЛЯ operation_parameters и diagnosis_parameters:
- Это списки параметров, ВЫРЕЗАННЫХ из того же абзаца (из "source_text").
- Не добавляй ничего “от себя”.
- Не включай условия/показания/противопоказания/возраст/сроки/частоту — это не параметры шага 1.

СПЕЦПРАВИЛО: РАЗБИЕНИЕ ДИАПАЗОНОВ ТИПОВ ПЕРЕЛОМОВ/КЛАССИФИКАЦИЙ
Если в абзаце встречается запись диапазона (через дефис/тире) вида:
  "<Префикс> A-B"
где A и B — степени/классы (например I-II, II-III, 1-2),
то В ПАРАМЕТРАХ нужно развернуть диапазон в отдельные элементы,
повторив префикс:

Примеры:
- "Garden I-II" → ["Garden I", "Garden II"]
- "Garden I–II" → ["Garden I", "Garden II"]
- "Pauwels II-III" → ["Pauwels II", "Pauwels III"]

Если диапазон однозначно перечислимый (например I-III или 1-3),
можно развернуть все уровни: I, II, III / 1, 2, 3.
Если развернуть однозначно нельзя — оставь исходную строку одним элементом.
